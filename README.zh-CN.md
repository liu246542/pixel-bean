# Pixel Bean — 拼豆图案生成器

上传图片，自动生成拼豆图纸、采购清单和逐步拼放指令。支持 AI 图片优化、多板分割和沉浸式专注模式。

**[English](./README.md)**

## 功能

### 核心
- **图片像素化** — 粒度预设（粗/中/细/精）或自定义输入，主色/均色两种模式
- **8 套色号系统** — MARD、COCO、漫漫、盼盼、咪小窝、Hama、Perler、Artkal-S（417 种颜色）
- **CIEDE2000 感知色差** — 比 RGB 欧氏距离更准确的颜色匹配算法
- **智能减色** — 可调阈值自动合并相似颜色
- **图案降噪** — 自动去除孤立的单格杂色（抗锯齿残留）
- **背景自动移除** — 洪水填充检测边界白色区域
- **颜色排除** — 点击排除不需要的颜色，自动重映射到最近色
- **图片裁剪** — 内置裁剪工具，支持比例预设（1:1、4:3、16:9 等）

### 拼板分割
- **多板拼图** — 将大图案拆分为 29×29 / 25×25 / 50×50 的拼豆板
- **预览叠加** — 红色虚线标注板块边界和 A1/A2/B1/B2 编号
- **完整板块** — 边缘板块补齐到标准尺寸，匹配实际拼豆板
- 贯穿所有模式：预览、PDF、专注模式、引导模式

### 专注模式（沉浸式拼豆）
- **全屏覆盖** — 无干扰的拼豆环境
- **按颜色引导** — 每次高亮一种颜色，其余变淡
- **区域一键标记** — 点击连通区域标记为已完成
- **勾选完成** — 整种颜色一键标记完成
- **十字准线** — 跟随光标的坐标提示（R15 C8）
- **板块切换** — 启用分割后可 ◀/▶ 切换板块
- **进度追踪** — 每种颜色进度条 + 总体完成数

### 引导模式（文字指令）
- **按颜色模式** — 逐色列出放置位置："第 5 行: C1-C8 (8), C22-C30 (9)"
- **按行模式** — 逐行列出所有颜色段（借鉴十字绣 Row Parking 方法）
- **板块分割** — 每块板独立指令，支持多人协作
- **预览图** — 可折叠的图案预览，高亮当前颜色/行
- **导出** — 复制到剪贴板或下载文本文件

### 导出
- **PNG 图纸** — 每格标注色号的网格图
- **PNG 统计** — 颜色图例（色块、色号、hex、数量）
- **PDF** — 多页：总览 + 分板详图（高粒度时自动分板）+ 颜色清单
- **CSV** — 兼容 Zippland/perler-beads 格式，支持导入导出

### AI 集成（可选）
- **AI 优化** — 将上传的图片转换为拼豆友好的平涂风格
- **AI 生成** — 根据文字描述直接生成图片，预填拼豆风格提示词
- **两步操作** — 第一次点击切换模式并填入提示词，第二次执行
- **实时进度** — WebSocket 推送 + 模拟进度条 + 预估时间
- **自动重试** — 失败后自动重试最多 3 次
- **心跳保活** — 防止 Cloudflare Tunnel 超时断连

### 其他
- **像素编辑** — 点击格子换色，支持撤销/重做（50 步）
- **手动保存** — 满意时点击保存到 localStorage，下次打开自动恢复
- **响应式布局** — 手机端顶栏置顶、单列堆叠
- **画布恢复** — 后台切回时自动重绘

## 项目结构

```
pixel-bean/
├── frontend/       纯前端静态页面（Vite + vanilla TypeScript，~50KB gzip）
│                   可部署到 GitHub Pages 或任何静态托管
├── ai-server/      可选的本地 AI 服务
│                   调用 Codex CLI，通过 WebSocket 通信，带队列和重试
└── docs/           设计文档和实现计划
```

前端独立运行，不需要后端。AI 服务仅在使用 AI 功能时需要。

## 快速开始

### 前端

```bash
cd frontend
npm install
npm run dev          # 开发服务器 http://localhost:5173
```

### AI 服务（可选）

```bash
cd ai-server
npm install
cp .env.example .env # 编辑 TOKEN 和代理设置
npm start            # 启动在 http://localhost:3456
```

需要安装 [Codex CLI](https://github.com/openai/codex) 并完成登录（`codex login`）。

### 构建部署

```bash
cd frontend
npm run build        # 输出到 dist/
```

部署 `dist/` 到 GitHub Pages 即可。推送到 master 时 GitHub Actions 自动部署。

## 使用流程

1. 上传图片（拖放或点击）
2. 选择**粒度**预设（粗/中/细/精）或输入自定义数值
3. 调节**减色**阈值（值越大颜色越少）
4. 选择**像素化模式**和**色号系统**
5. 可选：启用**拼板分割**
6. 排除不需要的颜色
7. **保存** → **导出图纸/统计/PDF/CSV**
8. 进入**专注模式**按颜色逐步拼放，或**引导模式**获取文字指令

### AI 功能

1. 输入 AI 服务地址并测试连接
2. **AI 优化**：将图片转为拼豆风格（平涂、少色、硬边缘）
3. **AI 生成**：输入描述直接生成拼豆风格图片

## AI 服务配置

```bash
# ai-server/.env
TOKEN=changeme              # API 认证密码
PORT=3456                   # 服务端口
https_proxy=http://127.0.0.1:8119  # 代理地址（如需要）
```

### Cloudflare Tunnel 部署

1. 将子域名指向 `http://localhost:3456`
2. 无需额外配置 — WebSocket 原生支持
3. 前端填入 `https://你的域名?token=密码`
